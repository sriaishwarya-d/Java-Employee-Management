Java Employee Management System

A Java-based employee management system that uses JDBC and MySQL to manage employee records.

Features
Add employee
View employee records
Update employee salary
Delete employee
Store employee details in a MySQL database
Display employee records from the database

How It Works

The program establishes a connection to a MySQL database using JDBC and provides a menu-driven interface for managing employee records.

Users can add employee details including employee ID, name, department, and salary. The program also provides options to view employees, update salary, and delete employee records.

Menu
========== Employee Management ==========

1. Add Employee
2. View Employees
3. Update Employee Salary
4. Delete Employee
5. Exit
Database

The program connects to a MySQL database named company and uses the employee table to store employee information.

Note: Before uploading this project publicly, database credentials should be configured securely instead of being stored directly in the source code.

How to Run
Install Java.
Install MySQL.
Configure the required database and employee table.
Add the MySQL JDBC driver to the project.
Configure the database connection.
Compile and run the Java program.
